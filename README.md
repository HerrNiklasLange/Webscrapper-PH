Web Data Scraper Project

This repository contains tools for scraping, processing, and visualizing publicly available video popularity data from an online platform. It was developed as a learning and portfolio project to explore web automation, data wrangling, and visualization.

⚡ Features

Automated scraping across multiple countries and time windows

Data backup to Excel/CSV for reliability

Fallback parsing methods for robustness

Randomized delays to avoid server strain

Example visualizations (trends, comparisons, rankings)

Python integration for automated WhatsApp notifications

📦 Tech Stack

R → Main scraping and data handling (RSelenium, rvest, openxlsx)

Python → Notifications and auxiliary scripting

Excel/CSV → Backup and storage

Git → Version control
